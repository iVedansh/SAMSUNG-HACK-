# Morrow Android

Android implementation of the Teachable Voice Assistant for the Samsung Hack project.

## Current milestone

- Native Android app foundation
- Accessibility Service declaration
- Voice command foundation using Android SpeechRecognizer
- Local routine model foundation
- Debug-friendly service status UI

## Build

Open this repository in Android Studio, let Gradle sync, then run the `app` configuration on an Android device or emulator.

The first prototype is intentionally focused on the Android foundation. Automation recording and replay will be implemented on top of the Accessibility Service rather than the Windows PowerShell implementation.
